# إزاي ترفع تعديل وتنشره

---

## الدورة الكاملة — 4 خطوات

```
1. تعديل الملفات
        ↓
2. اختبار محلي (npm run build)   ← أهم خطوة، متتخطاهاش
        ↓
3. رفع على GitHub (push)
        ↓
4. النشر (Deploy)
```

---

## الخطوة 1 — قبل أي حاجة: اختبر محليًا

**متعملش push قبل ما تتأكد إن المشروع بيبني.** لو فيه خطأ، النشر هيفشل أو الموقع هيقع.

```bash
cd /Users/user/Desktop/web-folder
npm run build
```

- ✅ لو خلص من غير أخطاء → كمّل
- ❌ لو ظهر `Failed to compile` → **متكملش**، ابعتلي الخطأ

> أول مرة بس محتاج `npm install` عشان ينزّل المكتبات.

---

## الخطوة 2 — الرفع على GitHub

```bash
git status
```
بيوريك الملفات اللي اتغيرت.

```bash
git add -A
```
بيجهّز كل التعديلات.

```bash
git commit -m "وصف مختصر للتعديل"
```
بيسجّل التعديل محليًا مع وصف.

```bash
git push origin main
```
بيرفعه على GitHub.

**علامة النجاح:** سطر فيه `main -> main`.

**لو طلب منك اسم مستخدم وباسورد:** GitHub مبقاش بيقبل الباسورد العادي — محتاج **Personal Access Token**:
1. ادخل https://github.com/settings/tokens
2. Generate new token (classic) → اختار صلاحية **repo**
3. انسخ التوكن واستخدمه **بدل الباسورد**

---

## الخطوة 3 — النشر (Deploy)

النشر بيحصل من **Coolify**. حسب إعدادك، فيه احتمالين:

**أ) نشر تلقائي** — لو Coolify مربوط بالريبو بـ webhook، الـ push لوحده بيبدأ النشر. تقدر تتابعه من لوحة Coolify.

**ب) نشر يدوي** — تدخل Coolify → تختار التطبيق → تضغط **Redeploy**.

---

## الخطوة 4 — التأكد إن التعديل ظهر

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://alifleet.com
```
لازم يرجع `200`.

⏱️ **مهم:** التعديلات اللي على **البيانات** (تليفون، منتجات، أسعار) ليها كاش **10 دقائق**. أما تعديلات **الكود** فبتظهر أول ما النشر يخلص.

## أوامر مفيدة

| عايز | الأمر |
|---|---|
| تشوف إيه اللي اتغير | `git status` |
| تشوف التغيير بالتفصيل | `git diff` |
| تلغي تعديل في ملف | `git checkout -- اسم-الملف` |
| تشوف آخر الكوميتات | `git log --oneline -5` |
| تشغّل الموقع محليًا للتجربة | `npm run dev` ← بعدين افتح http://localhost:3000 |

---

## ⚠️ أخطاء شائعة

| المشكلة | الحل |
|---|---|
| `npm run build` بيفشل | متعملش push. ابعتلي الخطأ |
| `push` مرفوض (rejected) | حد عدّل قبلك: `git pull --rebase` وبعدين `git push` |
| النشر نجح والموقع زي ما هو | امسح الكاش (Ctrl+Shift+R) أو استنى 10 دقائق |
| الموقع رجع 503 | Coolify — النشر فشل أو الكونتينر واقع |

---

## 🔑 القاعدة الذهبية

**تعديل بيانات** (منتج، سعر، مخزون، تليفون) → **ووردبريس** → مفيش push ولا deploy، بس استنى 10 دقائق.

**تعديل كود** (تصميم، نصوص ثابتة، ملفات SEO) → **الملفات** → `build` ← `push` ← `deploy`.
