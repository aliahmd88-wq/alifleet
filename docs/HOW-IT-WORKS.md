## 3) اللي تقدر تعدله بنفسك (ووردبريس) ✅

### أ) المنتجات — إضافة / تعديل / حذف

**المكان:** `wp-admin` → **Products**

| عايز تعمل إيه | إزاي |
|---|---|
| تضيف منتج | Products → Add New |
| تغيّر السعر | افتح المنتج → Product data → **Regular price** |
| تخلي منتج نافد | Product data → Inventory → **Stock status: Out of stock** |
| تخفي منتج | غيّر الحالة لـ **Draft** بدل Publish |
| تحذف منتج | Move to Trash |

> ⚠️ **مهم جدًا — الاسم والوصف اللي بيشوفه الزائر:**
> الموقع **مش** بيعرض عنوان المنتج العادي! بيعرض حقول ACF في آخر صفحة المنتج:
> - `name_ar` / `name_en` / `name_he` ← الاسم بالتلات لغات
> - `description_ar` / `description_en` / `description_he` ← الوصف
>
> لو غيّرت العنوان فوق بس، **مش هيتغير حاجة على الموقع**. لازم تعدل حقول ACF.

### ب) بيانات الاتصال وساعات العمل

دي مخزّنة في `wp_options`. أسهل طريقة تعدلها بنفسك: **قوللي وأنا أغيرها**، أو من:

`wp-admin` → **WooCommerce → Settings → General** (للعنوان والعملة)

أما التليفون والواتساب والإيميل فمخزنين في صفوف اسمها:
```
options_company_info_phone
options_company_info_whatsapp
options_company_info_email
options_company_info_hours
```

### ج) الطلبات

`wp-admin` → **WooCommerce → Orders** — كل طلب جديد هيظهر هنا.

### د) طرق الدفع والشحن

- الدفع: WooCommerce → Settings → **Payments**
- الشحن: WooCommerce → Settings → **Shipping**

**حاليًا مفعّل:** الدفع عند الاستلام (Cash on delivery) + الاستلام من المحل (Local pickup) فقط.

## 4) اللي محتاج تعديل كود (GitHub) ⚙️

| الحاجة | الملف |
|---|---|
| نصوص الصفحة الرئيسية والأقسام الثابتة | `lib/i18n/dictionaries/ar.ts` · `en.ts` · `he.ts` |
| صور الأسطول الافتراضية | `components/fleet-showcase.tsx` |
| التصميم والألوان | `app/globals.css` والكمبوننتس |
| مسارات الصفحات | `app/**/page.tsx` |

**الخطوات:** تعديل الملف → commit → push على GitHub → النشر بيحصل تلقائي.

> فيه استثناء: بعض الصور تقدر تتحكم فيها من ووردبريس بدل الكود، لو رفعتها في حقول ACF في صفحة الهوم (`fleet_vehicle_1/2/3`). لو الحقول فاضية، الموقع بياخد الصور من الكود.
