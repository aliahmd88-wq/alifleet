## ج) مشكلة `/en/home-en/` — الشرح

`alifleet.com` بقى **Next.js**. المسارات الموجودة:

```
/    /cars    /products    /contact    /blog    /cart    /checkout    /account/*
```

مفيش `/en` ولا `/ar` ولا `/he` — تبديل اللغة **داخل الصفحة** مش في الرابط. فـ `/en/home-en/` رابط ووردبريس قديم مبقاش موجود → 404 طبيعي.

**الأثر على SEO:** 3 لغات على رابط واحد = جوجل يفهرس نسخة واحدة. العربي والإنجليزي **غير مرئيين** في البحث.
